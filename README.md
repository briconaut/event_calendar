# Event Calendar

Pflegt drei private Google-Kalender – **Weihnachtsmärkte**, **Feuerwerke** und **Events und Feste** –
aus den Daten in diesem Repository. Das Repository ist führend; die Kalender werden per Claude Code
(Web) und Google-Calendar-Connector abgeglichen.

- Spezifikation: [`docs/spec.md`](docs/spec.md)
- Umsetzungsplan: [`docs/tasks/`](docs/tasks/)
- Regeln für Agenten: [`CLAUDE.md`](CLAUDE.md)
- Fertige Aufträge: [`prompts/`](prompts/)

Typische Nutzung: neue Web-Session auf diesem Repo starten und den Inhalt einer Datei aus `prompts/`
als Auftrag einfügen.
